# H3 硬点清单（换轨时必查）

> 换轨过程中**最容易漏**的 H3 规范硬点。权威定义一律以 `h3-prompt-writing` 的
> `references/ref-en.txt` 与 `references/base-en.txt` 为准，本文件只做「换轨前的检查索引」，
> 不重定义字段。凡与规范冲突，以规范为准。

---

## 一、summary 必须以方括号任务类型前缀开头

这是六段式里最容易整段漏掉的结构性元素。

```text
summary: [reference generation + keyframe completion] A 16:9, 15-second ...
```

| 任务类型 | 何时用 |
|---|---|
| `keyframe completion` | 图片充当目标视频的首帧／关键帧／尾帧／剪辑后关键帧或其他具体帧锚点 |
| `reference generation` | 图／视频／音频提供人物、场景、风格、动作、运镜、分镜等生成指引，**但不充当具体帧，也不是被剪辑或被续接的源视频** |
| `video editing` | 直接修改一段既有源视频（剪辑图片、或在静帧之间生成**不属于**此类） |
| `video continuation` | 新内容续接、延长、恢复或过渡自一段既有源视频 |
| `audio reuse` | 同一音频信号被全部或部分复用 |
| `audio reference` | 不直接拷贝信号，只参考其音乐风格、音色、台词／歌词内容、音效质感、节拍或连续性 |

规则：

- 多个关系同时成立时用 ` + ` 组合，**同一类型不重复**，如 `[video continuation + keyframe completion]`
- **仅出现视频或音频不等于就要建对应任务类型**：参考视频只提供运镜／剪辑／节奏时，算 `reference generation`
- 剪辑源视频且原声仍可听 → 追加 `audio reuse`
- summary 里用已定义的 `<Subject N>` 等标签描述主体、镜头流与资产作用，**不得引入新标签**
- 视频剪辑任务在任务类型前缀之后固定起句：`The target video is an edited version of <Video 1>.`

## 二、`detailed_description` 的词数

**规范值：350–500 英文单词**（生成类任务）。

- 对话密集的内容以「说完整条对白时间线」优先，不必机械凑词数
- 视频剪辑类描述随源视频复杂度伸缩，不受此区间约束
- **单镜短不代表整段可以短**：按各镜信息量分配细节
- 按实测英文比例（约 5.85 字符／词）折算：**350 词 ≈ 2050 字符，500 词 ≈ 2930 字符**

> 这条与「字符总量」是两个维度。字符总量约束见 §七。

---

## 三、`overall_soundscape`

- **1–4 句英文，一个连续段落**
- 内容 = 全片环境声 + 物理动作声 + 非语言人声（风、雨、脚步、衣料摩擦、撞击、呼吸、笑、喘）
- **对白、唱段、可被角色听到的音乐已属 `detailed_description`，此处不得重复**
- `N/A` **只在用户明确要求全片完全静音时**才用

## 四、`non_diegetic_music`

- **1–3 句英文**
- 写配器、速度、节奏、动态变化
- **不要用抽象情绪词，不要解释配乐的情绪功能**
- 角色能听到的唱段／乐器／收音机／电视／手机音乐属 diegetic，应写进 `detailed_description`
- **无配乐时写 `N/A`** —— 这是固定值，不要自己造句

## 五、跨切对白与截断

| 场景 | 写法 |
|---|---|
| 同一句对白／唱词跨切镜继续 | 在切点两侧都标 `<scenetrans>`，并明确说明音频跨切延续 |
| 对白被视频结束截断 | 标 `<cutoff>` |
| 连续性表述 | `continues seamlessly across the cut` / `continues uninterrupted into the next shot` / `carries over from the previous shot` / `remains audible across the transition` |

## 六、画面可见文字

横幅、招牌、标签、字幕、霓虹字等**画面里真实可见**的文字：

- 用**英文双引号**包住
- **原文与标点逐字保留，不翻译**

```text
A red neon sign reading "营业中" glows above the doorway.
```

## 七、说白、唱词与画外音

- `<d>[Language] 内容</d>`，语言标签必须在最前
- 直接复用参考音频的台词／旁白／歌词，或用户明确要求复现时，**逐字保留原文与原语言**
- 听不清的片段写 `[unclear]`，**不要猜写或改写**
- 标点规范化到 `,` `.` `?` `!`；去掉重复波浪号、emoji、项目符号、装饰性标点
- 画外音固定用 `says in an off-screen voiceover`，并在**每个**画外音 `<d>` 之后紧跟一句说明对应角色的嘴唇完全不动

## 八、风格起句

- 风格词表：`Cinematic` / `live-action` / `2D-animated` / `3D CG` / `claymation` / `watercolor` / `vintage film`
- **Ref2VA**：风格与初始构图写成 `[Shot 1]` **之前**的 1–2 句英文
- **T2VA**：写在 `[Shot 1]` 之后
- 关键帧任务（I2VA 等）从参考图推导风格

## 九、各模式的关键帧口径

| 模式 | 口径 |
|---|---|
| I2VA | `<Picture 1>` 是 0.00 秒真实首帧，属 `[Shot 1]`；结构：首帧锚定 → 动作开始 → 连续发展 → 结果 |
| FL2VA | Picture 1 是起幅、Picture 2 是落幅；**一般偏单镜**以便模型连续插值，除非明确要求多镜；尾帧必须由最后一个 `[Shot N]` 在视频末尾到达 |
| L2VA | `<Picture 1>` 是**尾帧**，属最后一个 `[Shot N]`，**不天然属 Shot 1**；结构：合理前置状态 → 明确动作与过渡路径 → 末镜收敛 → 落到尾帧 |

## 十、本技能引入的工程纪律（**非 H3 规范所载**）

以下四条来自镜头库经验与 MiniMax 平台的工程实践，`h3-prompt-writing` 规范里**没有**这些约束。
写文档或与人对齐时要标明出处，不要当作 H3 官方要求。

| 纪律 | 出处 | 说明 |
|---|---|---|
| **一镜一动词** | 50 镜镜头库硬经验 | H3 规范只说「运镜写成自然英文动作」，未限制每镜动词数。本技能按镜头库口径从严要求 |
| **单段 ≤ 7000 字符** | 工程／平台预算（**规范未载**） | 规范对字符总量无约束，只有 §二 的词数参考。此值按实际接口的输入上限核对后再定 |
| **场景词收敛** | 镜头库使用纪律 | 防止模型串场 |
| **段间接帧** | 本技能工程实践 | 多次独立生成之间没有内在连续性，靠把上段实际末帧作为下段 `<Picture N>` 承接 |
| **背景人群约束句** | 本技能工程实践 | 需要环境人群又必须保证主角唯一时的写法 |
