# 换轨映射表

> 《H3 镜头库适配器》的逐词映射层。用于把镜头库中文原文里的运镜、景别、光位表述，换成 H3 认得的英文表述。

---

## 一、运镜换轨：中文动词 → H3 三元组

H3 的运镜词汇是**闭集**，只有下表左列这些运动类型。中文的「跟」「移」「推轨」「摇升」在 H3 里没有一一对应词，必须归到最近的一个。

| H3 运动类型 | 含义 | 库内常见中文说法 |
|---|---|---|
| `Zoom In / Zoom Out` | 机身不动，焦距变 | 变焦推近、拉远、急推 |
| `Push In / Pull Out` | 机身前后移动 | 推近、推、缓推、拉远、后拉 |
| `Pan Left / Pan Right` | 机身不动，镜头水平摇 | 水平摇镜、左摇、右摇、扫景 |
| `Truck Left / Truck Right` | 机身水平横移 | 平移、横移、移轴横向、机位横移 |
| `Tilt Up / Tilt Down` | 机身不动，镜头垂直摇 | 摇升、摇降、上摇、下摇 |
| `Pedestal Up / Pedestal Down` | 整机升降 | 升机位、降机位、升降 |
| `Arc Shot` | 绕主体弧线运动 | 环绕、绕拍、弧线运镜 |
| `Tracking Shot` | 跟随移动主体 | 跟拍、跟随、推轨跟拍、追拍 |
| `Static Shot` | 机位与镜头全静 | 固定、静止、纹丝不动、机位不动 |
| `Shake Slightly / Shake Strongly` | 机身抖动 | 手持微晃、手持剧烈晃动 |
| `POV` | 主体视角 | 第一人称视点、主观视角 |
| `Roll Clockwise / Roll Counterclockwise` | 绕光轴滚转 | 逆时针旋转、倾斜旋转 |

**幅度**：`with small amplitude` ／ `with large amplitude`
**速度**：`at slow speed` ／ `at fast speed`

> 中等幅度与常速**通常省略不写**。全句都挂满幅度和速度反而会稀释重点。

### 1.1 归并规则（中文多动词 → H3 单动词）

库内原文大量出现「摇升」「推轨跟拍」「手持跟拍」「倾斜跟拍」这类复合词。**复合词必须归并成一个 H3 运动类型**，否则违反一镜一动词。

| 库内原文复合词 | 主运镜取 | 次运镜怎么处理 |
|---|---|---|
| 摇升（边摇边升） | `Tilt Up` | 「升」的速度并入 speed 维度 |
| 摇降 | `Tilt Down` | 同上 |
| 推轨跟拍（正向推进 + 跟人） | `Tracking Shot` | 「推进」写成 with large amplitude；**不要**再叠 Push In |
| 手持跟拍（手持 + 跟人） | `Tracking Shot` | 手持质感写成画质修饰短语：`the frame shaking strongly as it holds tight on her back`，**不并列第二个运动类型** |
| 倾斜跟拍（对角线 + 跟人） | `Tracking Shot` | 倾斜写成构图描述：`the horizon canted to hold her body on the frame's diagonal` |
| 垂直俯拍慢移 | `Pedestal Down`（或 `Truck` 视方向） | 「俯拍」是机位角度不是运镜，写在画面描述里 |
| 焦点平滑推向背景 | `Static Shot` | **焦点变化不是运镜**，用 `the focus racks from ... to ...` 描述 |
| 命中处小幅快推（叠在主运动上的强调） | 主运镜取原运动 | 快推**不要**并列成第二个运动类型；改成震机 `the frame shaking strongly once on the contact` 或插入切镜 |
| 缓缓推近 + 固定（同段自相矛盾） | 取推近 | 见 §五 缺陷 7 |

**手持的写法模板**：

```text
[Shot 3] At 00:06.500, the camera holds a handheld tracking shot that shakes strongly as it stays
tight behind her back, with small amplitude at fast speed.
```

## 二、景别与焦段

H3 无闭集，用通用英文术语即可，但要**具体到焦段**，这是「具体描述」最省字的抓手。

| 库内中文 | H3 英文 | 备注 |
|---|---|---|
| 远 / 大全 | `extreme wide shot` | |
| 全景 / 全貌 | `wide shot` / `full shot` | 全身入画用 `full shot` |
| 中景 | `medium shot` | |
| 中全景 | `medium full shot` | |
| 近景 | `medium close-up` | |
| 特写 | `close-up` | |
| 极近距离 / 大特写 | `tight close-up` / `extreme close-up` | |
| 微距 / 微观质感 | `macro` | |
| 过肩 | `over-the-shoulder` | |
| 双人同框 | `two-shot` | |

焦段写法：`an 85mm close-up`、`a 100mm macro`、`a 24mm wide shot`。库内「大光圈虚化」写成 `shallow depth of field`。

## 五、文体改写：抽象词清洗表

H3 明确要求「prefer concrete visual and audio details over abstract words」。库内高频抽象词逐条给出替换方向：

| 抽象词 | 处理 |
|---|---|
| 电影级 / 电影感 | ⚠️ **分两种用法**。作**风格标签**在 `[Shot 1]` 开头用一次是**合法的**——H3 规范自己的风格词表就含 `Cinematic`（`Cinematic` / `live-action` / `2D-animated` / `3D CG` / `claymation` / `watercolor` / `vintage film`）。作**填充形容词**在镜头描述里反复出现时才删 |
| 极致 / 拉到极致 | 删 |
| 张力拉满 | 删。改用「对角线构图 + 手持微晃 + 快步频」承载 |
| 尽显 / 凸显 / 完美凸显 | 删。改成「光位怎么打、打出什么形状的阴影」 |
| 毫发毕现 / 细节分明 | 改成具体材质：「刀伤的结痂边缘」「指关节暴起的青筋」 |
| 视觉冲击力极强 | 删。改用「大反差明暗 + 硬切」承载 |
| 肾上腺素飙升 | 删 |
| 行云流水 | 删。改用运镜的幅度与速度形容词 |
| 凄美 / 唯美 | 删。改用具体光位与色调 |
| 意境悠远 / 余音绕梁 | 删。改用留白比例与时长 |
| 空气为之凝固 | 删。改用 `static shot` + 无对白时长 |
| 如火如荼 | 删 |
| 心理惊悚 / 新黑色电影（作为体裁标签） | 删体裁词，只留具体的光与构图 |
| 神秘 / 神圣 / 恐怖（作为氛围结论） | 删结论，只留产生该感受的具体元素 |

**原则：抽象词一律不给替代词，只删；删掉后靠「景别 + 焦段 + 光位 + 材质 + 动作节拍 + 时长」把它撑起来。** 这也是字数能压下来的主要空间。

**唯一的例外是风格标签**：H3 要求 `[Shot 1]` 开头交代整体风格与初始构图，这里的风格词是从规范给的表里选的，属于必要字段，不算抽象填充。区分标准是**位置与次数**——`[Shot 1]` 开头一次即止，之后不再出现。

### 5.1 三条改写对照（完整前后）

**例 1 · 11 号慢动作升格镜**

库原文：`120帧高帧率升格，[角色名]挥拳斩断半空中的玻璃碎片，原本转瞬即逝的动作被极致拉长，碎片切开空气的物理形变，四溅的玻璃在空中缓慢绽放的轨迹清晰可辨，动作凌厉而凄美，时长3秒`

换轨后：

```text
[Shot 2] At 00:04.000, the shot cuts to a 100mm close-up and drops into slow motion. Her fist
passes through a glass shard hanging in the air; the shard splits, and the two halves drift
apart with the broken edge catching a bright line of light. Her sleeve snaps back a beat
behind her arm.
```

删掉「高帧率」（改成 `slow motion`）、「极致拉长」「凌厉而凄美」（无替代）、「物理形变」（改成可见的裂开与漂移）。

**例 2 · 6 号俯拍众生镜**

库原文：`无人机垂直俯拍慢移镜头，机位从都市十字路口天井正上方鸟瞰，缓缓平移，在这个后末日废墟中，密密麻麻的幸存者队列如蝼蚁般缓慢前行，寻找出路的全貌尽收眼底，街道呈现规则的几何排列，时长10秒，尽显群像的命运暗流`

换轨后：

```text
[Shot 1] A top-down overhead shot looks straight down onto the crossing. The camera trucks right
with small amplitude at slow speed. Survivors fill the streets in dense, evenly spaced columns,
each figure no longer than a thumbnail in frame, all of them moving in the same direction.
The road markings cut the crowd into four exact rectangles.
```

删掉「无人机」（H3 不需要载具）、「如蝼蚁般」（改成「不超拇指长」这个可拍的长度）、「尽收眼底」「命运暗流」（无替代）。

**例 3 · 3 号特写情绪镜**

库原文：`心理惊悚特写镜，极近距离拍摄[角色名]紧握打火机的右手，打火机上的磨损痕迹与指关节暴起的青筋细节分明，当打火机被反复按压却无法点燃时，画面降速至0.5倍，冷光在金属表面轻微起伏，背景呈现纯粹的暗调虚化`

换轨后：

```text
[Shot 3] At 00:08.000, the shot cuts to a tight close-up on her right hand around the lighter.
The chrome is worn to bare brass along one edge; the tendons stand out across her knuckles.
The thumb presses and releases three times with no flame, and the motion drops into slow motion
on the third press. A cool highlight slides along the metal as her hand trembles. The background
is entirely black.
```

删掉「心理惊悚」（体裁标签）、「细节分明」（被具体材质顶掉）、「纯粹的暗调虚化」（改成 `entirely black`）。

## 六、缺陷 7：布光镜组内的运镜自相矛盾

上游技能记录的 6 处缺陷是**场景标签互斥**（33/35/37/39/43/44）。本技能在使用中发现第 7 处：

> 硬纪律 2 声明「41–48 号人像布光镜**全是固定机位**」，但库内 44 号（底光恐怖，`镜头缓缓推近`）与 47 号（环形光，`镜头缓慢微推`）原文都带运镜。

**处理口径**：

- 44、47 的推近是**有效的心理压迫手法**，不是错误。这两条**保留推近**，但必须补全幅度与速度：`pushes in with small amplitude at slow speed`。
- 其余 40–43、45、46、48 保持 `Static Shot`，**加运镜会破坏光位关系**。
- 引镜时若不确定，优先服从原文的运镜；纪律 2 的用意是「不要给纯布光镜硬加运镜」，不是「把原有的推近删掉」。
