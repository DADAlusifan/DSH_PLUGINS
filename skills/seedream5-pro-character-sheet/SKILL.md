# Seedream 5 Pro 角色设定提示词

将用户的角色想法整理为自洽、可复用、可直接粘贴至 Seedream 5 Pro 的中文提示词。优先保证角色身份、外观、服装结构与配件之间有一致的视觉逻辑，不堆砌无关形容词。
## 工作区交付

如果当前会话存在可写工作区，必须将本次**完整交付**写入一个 UTF-8 编码的 Markdown 文件，而不是只在聊天中输出内容。

- 每个角色必须使用独立角色文件夹，默认路径为 `<工作区>/角色/<角色名或主题>/角色设定.md`；不得将不同角色的设定文件直接混放在工作区根目录或同一个角色文件夹中。
- 清理角色文件夹名中的非法字符；角色名缺失时使用 `<工作区>/角色/未命名角色/角色设定.md`。
- 用户指定目录或文件名时优先使用其指定位置；除非用户明确要求，否则仍应在该位置下为每个角色创建独立子文件夹。
- 同一角色文件夹内的目标文件已存在时不得静默覆盖；改用递增文件名，例如 `角色设定-2.md`。角色相关参考图、变体设定或后续文档也应保存在同一个角色文件夹内。
- Markdown 文件必须包含完整的"角色设定卡、详细设计、Seedream 5 Pro 主提示词、负面约束、关键假设"。用户只要 prompt 时，文件至少包含"Seedream 5 Pro 主提示词、负面约束、关键假设"。
- 写入成功后，聊天中只简短说明已生成内容并给出绝对文件路径；用户明确要求在聊天中完整展示时再同时展示全文。
- 如果没有可写工作区或文件写入失败，则在聊天中输出完整交付，并简短说明未能保存的原因。

## 默认画面硬约束

除非用户明确改写，所有实际出图提示词必须包含以下约束：

- 画面仅一位角色；默认角色为成年人，未成年角色必须避免成人化描述。
- 完整全身**正面设定图**，正常直立，自然对称站姿，双手自然垂于身体两侧。
- 正面平视全身镜头，人物居中，头顶、手部与鞋履完整可见。
- 纯净灰白色影棚背景，无场景、无文字、无边框、无拼图、无多视图、无人像重复。
- 以角色设定与服装辨识度为优先，使用清晰柔和的棚拍光，材质真实可读。- 默认成年角色采用腿部视觉比例显著修长的"大长腿"体态：腿长突出、腰线偏高、膝盖与脚踝位置自然、骨骼结构合理；用户明确指定矮小、短腿、幼态比例或特殊物种比例时，以其要求为准。

如果用户指定半身、动态姿势、道具、深色背景或其他版式，执行指定内容；但仍要在提示词开头锁定人数、视图、镜头和画面边界。

## 工作流

### 1. 提取需求与补全缺口

先识别角色身份、年龄段、性别表达、世界观、职业、气质、核心视觉符号、服装限制与用户明确不要的元素。信息不足时做少量且合理的补全，并在交付末尾列出关键假设。

优先确定 3 至 5 个视觉锚点，例如发型轮廓、主色与点缀色、服装主结构、标志性材质、核心配件。避免在同一角色上混入互相冲突的时代、文化或职业符号。

### 2. 构建设计层级

按以下顺序扩写，确保每项都服务于角色身份：

1. 角色定位与整体气质。
2. 面容、发型、妆容、肤色和体态。
3. 服装：内层、中层、外层、腿部与鞋履。
4. 配件：主装饰、辅助装饰、功能性物件。
5. 主色、辅色、金属、布料、皮革等材质，以及磨损或工艺细节。

外观描述应具体、可观察。用明确的剪裁、位置、数量、颜色和材质替代笼统的"华丽""高级""精致"。

## 精细艺术设计标准

每次角色设计都必须先建立**角色 DNA**：身份与人生阶段、欲望或矛盾、世界观位置、核心视觉隐喻、主轮廓、主色/点缀色、标志性材质与一个不可替代的记忆点。所有外貌、服装与道具细节都必须服务于这套 DNA，避免成为彼此无关的华丽元素拼贴。

在"详细设计"中，至少逐项完成以下内容；信息不足时做有依据的最少补全：

1. **脸部与头发**：脸型、五官重心、眼神、肤质、妆容逻辑、发型轮廓、发饰结构与动态。
2. **体态与剪影**：身材比例、重心、姿态习惯、肩腰腿的视觉节奏，以及远距离仍可识别的轮廓；除非用户明确反向要求，成年角色必须写明"修长大长腿、高腰线、自然膝盖与脚踝比例"。
3. **服装工程**：内层、中层、外层、腿部与鞋履；每层都写清结构、开合方式、贴合或飘逸的原因、功能性与活动余量。
4. **材质与工艺**：布料织法、金属表面、皮革处理、刺绣/纹样位置、透明度、磨损、旧化或保养状态；材质对比必须支持角色身份与世界观。
5. **饰品、武器与道具**：主次关系、佩戴或悬挂位置、使用痕迹、叙事来源与其对剪影的贡献。
6. **色彩与光影**：主色、辅色、点缀色、冷暖关系、明度层级与建议光线；避免平均用色或无重点的彩色堆叠。
7. **艺术节奏**：留白、疏密、重复纹样、材质对照、刚柔对比和视觉焦点，确保角色既有近看细节，也有远看气质。

不得只写"华丽、精致、高级、仙气"等空泛形容词。应以可见、可绘制、可复现的具体结构、位置、比例、材质与光线替代。角色性感、威严、脆弱或危险等气质，也必须由剪裁、姿态、表情、材质和构图共同呈现。

## 多 Agent 协作（复杂角色按需启用）

当角色为主角、核心反派、系列常驻角色，或同时满足复杂世界观、跨文化元素、复杂服装工艺、多个核心道具、高艺术风格要求中的两项以上时，若协作能力可用，应采用多 Agent 协作。简单角色可由主 Agent 完成，但仍必须执行下述自检。

建议分工：

- **角色概念设计师**：负责角色 DNA、叙事身份、人物矛盾、轮廓与记忆点。
- **服装与材质设计师**：负责服饰分层、结构合理性、工艺、饰品、武器与材质逻辑。
- **艺术总监/一致性审查者**：检查色彩、剪影、视觉焦点、文化元素、艺术感与 Seedream 5 Pro 的画面可执行性。

主 Agent 必须整合而非拼接各方结果：解决冲突、保留最强视觉锚点、删去冗余装饰，并让最终角色成为一个完整的人。交付前记录是否启用了协作；未启用时，说明任务为何可由单一设计流程可靠完成。
### 3. 编写 Seedream 5 Pro 提示词

使用中文分段自然语言，按下列顺序组织：

1. **画面硬约束**：人数、全身正面设定图、镜头、姿态、灰白背景。
2. **角色身份与气质**：职业、年龄段、世界观、整体视觉方向。
3. **面容与体态**：发型、五官、表情、肤质、比例与站姿；成年角色默认明确写入"修长大大长腿、腿部视觉比例显著偏长、高腰线"。
4. **服装与配件**：从内到外，说明关键结构、配色、材质和佩戴位置。
5. **构图与光线**：居中、完整可见、棚拍光、材质可读。

第一句必须明确写出"画面仅一位角色、完整全身正面设定图、灰白色影棚背景"。如角色为女性或男性，可在第一句补充，但不要在用户未要求时擅自指定性别。

### 4. 写精简负面约束

提供一个短的中文负面约束块，优先防止：多人物、重复人物、背面或侧面、拼图、多视图、局部裁切、文字水印、复杂场景、额外道具、畸形肢体、错误手指、短腿、五五身比例、膝盖或脚踝位置错误、服装结构错位，以及用户明确不要的元素。

不要在负面约束中堆砌大量抽象质量词，也不要放入会与正面设定图要求冲突的内容。

## 交付格式

默认按以下顺序输出：

1. **角色设定卡**：角色名、定位、气质、关键词、视觉锚点。
2. **详细设计**：角色 DNA、脸部与头发、体态与剪影、服装工程、材质与工艺、饰品/武器、色彩与光影、艺术节奏。
3. **Seedream 5 Pro 主提示词**：可直接粘贴的中文分段提示词。
4. **负面约束**：精简中文列表或一段短语。
5. **关键假设**：仅列出因信息不足而补全的内容。

如果用户只要 prompt，只保留第 3、4、5 项。用户明确只需简短版本时，不输出详细设计说明。

## 交付前检查

- 主提示词第一句是否锁定单人、完整全身正面设定图与灰白影棚背景。
- 角色是否只有一套自洽的身份、色彩、材质和服装语言。
- 服装是否有清晰层次，配件是否有主次与合理位置。
- 是否保证头、双手与鞋履完整入画，并避免人物重复或多视图版式。- 成年角色是否已在主提示词中明确写入"修长大长腿、高腰线"，并在负面约束中避免短腿、五五身与腿部畸形；用户反向要求时除外。
- 是否只输出 Seedream 5 Pro 版本，不附带其他模型格式。
- 是否尊重用户明确指定的镜头、背景、姿态、年龄、服装或避免项。
- 工作区交付时，是否已将文件写入对应角色的独立文件夹，而非混放在根目录或其他角色目录。
- 是否已逐项落实脸部、剪影、服装工程、材质工艺、配件、色彩与艺术节奏，而非堆砌抽象形容词。
- 复杂角色是否已按需完成多 Agent 协作或单一流程自检，并将结论整合为一套无冲突的角色 DNA。
