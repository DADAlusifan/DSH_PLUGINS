# 角色设定方法（美术统筹级）

> 用途：为小说中的每个角色建立一份《角色设定.md》+ 定妆参考图，让全剧出图环节引用同一套人物定义，防止角色漂移与形象撞车。
> 目标层级："美术统筹级"——读得出美与灵魂，不是"裁缝工程说明书"。

---

## 一、先诊断，再动笔：必须避免的七种毛病

| 病症 | 表现 | 后果 |
|---|---|---|
| 工程化 | 写克重、支数、包边毫米、透光率 | 模型读不到"美"，只读到参数 |
| 无意象 | 服装只是"某朝代某形制" | 角色没有灵魂锚点，全像同一套模具 |
| 无异象 | 只有一句"身后有法相" | 缺少不可替代记忆点，缩略图认不出 |
| 神态空洞 | "冷艳""妩媚""温和" | 画出来是一张没有情绪的脸 |
| 姿态僵硬 | "自然站姿、双手垂于两侧" | 像证件照，没有故事 |
| 配色平淡 | 颜色平铺，无主次 | 没有渐变逻辑与冷暖叙事 |
| 缺氛围 | 只有"棚拍柔光" | 没有镜头语言、光位、风格锚 |

---

## 二、写法内核（九条）

1. **一个意象贯穿全身**。角色有一个"意象锚"（如：花·月·骨），从脸（印记）→ 发 → 衣 → 配饰 → 异象，全部服务同一个隐喻，彼此不是拼贴。**意象锚全库唯一**，一人一个，防撞。
2. **自造诗性材质名**。不写"电力纺"，写"像被月色泡软的熟丝"——材质名本身就是美术方向。
3. **双层气质对峙**。每个角色写清：哪一层是壳、哪一层是漏出来的光、两者的对峙方式（同时存在，不是交替）。
4. **十五个可绘制面部细节**。逐条写：脸型骨相／眼型眼睑／瞳色虹膜／睫毛卧蚕／眉形眉态／鼻型鼻翼／唇形／唇态齿舌／颊色／印记瑕疵／耳与耳饰／妆容／表情微动态／生理细节／颈锁衔接。写到"毛细血管级"。
5. **不可替代记忆点＝实体化异象**。一个一眼能认出的实体奇观，并写明它随情绪如何变化（越亮越宽／越急越密）；异象必须有"只作背景不遮本尊"的锁定句。
6. **姿态有故事**。重心偏一侧、肩线成斜线、一只手正在做某件事、足尖虚点——写成一个正在发生的瞬间，不是"站着"。
7. **配色有逻辑**。主色（占面积最大）＋辅色＋点缀色（只在小面积高浓度处），写明冷暖节奏、明度层级、禁止色。诗性色名，不写色号。
8. **焦点管理 ≤3**。唯一主焦点（画面最亮处）＋两个次焦点，说明三角分布与视线先后。
9. **提示词八段式**（可直接复制）：①画质 → ②构图与视图 → ③人物与神态 → ④异象特效 → ⑤发型发饰 → ⑥服装分层详写 → ⑦皮肤质感与饰品鞋履 → ⑧瞳光/背景/光线/风格。末尾附参数建议。

## 三、语法级模板（每个角色必备的四件套）

### 1. 壳/芯口诀（一句话）
```
〈上层冷态〉是壳、〈下层状态〉从〈具体出口〉漏出来。
```
配套**节拍口诀**：
```
眼为主语、〈某饰物〉为节拍：X 冷则 Y 紧、X 融则 Y 松。
```

### 2. 情态定位＝单帧定格（不写形容词）
```
欲已动而神未肯认，卡在「〈四字意象〉未落」的帧。
```
要点：这一帧里没有"媚笑"这种结果，只有"正在把某状态收回去"的过程——动作已发生、状态未完成。

### 3. 色彩面积纪律
```
主色约 60%（占画面绝对面积、唯一的底色语言）＋辅色约 25%＋点缀约 10%。
```
- 点缀只落在焦点区（额／唇／某配饰／踝），收束句固定："**禁彩虹式平均堆叠**"
- 冷暖公式：冷色兜底 ＋ 在特定区域渐出干净暖点，两色交界沿某个具体结构形成一条过渡带
- 光影三层＋叙事线：冷调主光 → 1–2 处定向焦点光 → 极低功率背景光晕（只作背景不遮本尊）

### 4. 遮露节奏五拍
```
蔽 → 露 → 遮 → 露 → 收
```
- 收束句：`遮与露交替呼吸，每处裸露都被〈某工艺〉收口，是有设计的艺术感而非拼贴露点`
- **铁律：所有露肤由服装结构产生**（横带止点／袖位／开口／开衩），不是"裸体"，也不是"半裸"；每处裸露都写明结构来源

## 四、数字使用规则（三用三不用）

- **用**：人体基准（一律相对词，如"重心略偏一侧、右足后撤半脚"）／服饰止点与起点（决定露肤边界，必须写）／图案计数（只写在设定层）
- **不用**：脸上任何数字／克重与支数／透明率百分比与色号
- 量纲偏好**身体单位**：约一掌、两指、三指、一指宽、三寸、指尖盖
- **铁律**：织造参数只许留在设定的服装工程栏作"可绘制性证明"，**不得进入主提示词**；提示词里的数字只能是"露肤边界"

---

## 五、负面约束四段式

1. **防通用**（低质、糊、扭曲）
2. **防构图畸形**（多指、断肢、比例崩坏）
3. **防服装错位**（衣物结构错乱、配饰增减）
4. **防专属负面**（本角色特有崩坏，如"X 糊成一团""X 与 Y 各画各的""裸露处被布料重遮"）

写实质感段：全画幅＋85mm 定焦、f/2.8、1/160s、ISO 100、真实毛孔与细纹、不做磨皮；负面加"塑料感皮肤／过度磨皮／蜡像感／3D CG 感／插画二次元感"。

---

## 六、证据纪律（从小说长出来的设定）

1. **从原文逐句提取**：建立《人物资料提取_第N-M章.md》，逐句带行号，作为设定的事实底稿
2. **关键假设分级**：每条假设区分【原文依据】与【设计补全】；标注证据强度（★★★★★ 有大量原文描写 ～ ☆ 全为推定设计）
3. **变体隔离**：幻境扮相/特殊造型属角色的变体小节，不另立角色、不与本体混用
4. **成年声明**：全部角色为成年人（女性视觉年龄给定区间）；男主类角色按需要决定是否做露肤设计

---

## 七、廓形互斥检查（全库防撞）

出一张**服装差异化总表**，全角色逐项互斥，每人每类只占一样：

| 互斥维度 | 检查点 |
|---|---|
| 领型 | 交领／齐胸横带／心形浅V／高立领／抹胸／方领／挂脖……一人一个 |
| 开衩方位 | 右侧／左侧／前中／双侧／无——方位也是签名 |
| 鞋履 | 靴／鞋／赤足／履……逐人互斥 |
| 纹样 | 同源纹样也要拆分（如成对／单个／只取其一），写明拆分逻辑 |
| 廓形结构 | 主线结构（横带切分／鱼尾／高立领交叠……）逐一对照 |
| 主色 | 主色不得重复；同色系者错开明度与冷暖 |

**纹样拆分为防撞要义**：若两个角色共享一个纹样母题，必须在设定里写清"各自只占哪一部分、在缩略图上不会被读成同一件"。

---

## 八、一致性锁定（防漂移）

- 变体稿（换装/换场景）**必须保留**：发型三段结构、瞳色、印记、异象、主色——否则角色漂移
- 一致性锁定句首尾各出现一次：`〈发型发饰／异象／主色／纹样〉【必须与主设定完全一致】`
- 参考图命名规则：单张不加编号，多张按生成时间从（1）起

---

## 九、单角色文件结构（推荐）

```
# <角色名> 角色设定（出图工具名）· 版本定稿
> 出处（章节范围）｜成年声明｜本文件只写外观/服装结构/异象的可绘制信息
> 画面硬约束（单人/全身/背景/入镜范围）
> 意象锚：…｜实体化异象（不可替代记忆点）：…

## 一、角色设定卡          ← 身份表 + 记忆点清单（3-5 条）
## 二、详细设计
   1. 角色 DNA            ← 身份/欲望矛盾/世界观位置/防撞分析/核心隐喻/主轮廓/主色/材质/禁忌线
   2. 脸部与头发          ← 双层气质 + 十五细节 + 情态定位 + 发型 + 发饰布局
   3. 体态与剪影          ← 骨相/比例/体态/具体姿态（有故事的瞬间）/剪影识别信息
   4. 服装工程            ← 内层/中层/外层逐层：剪裁结构/开合/材质/工艺/露肤逻辑
   5. 异象设计            ← 实体化异象的运作规则与随情绪变化
   …
## 三、主提示词（八段式 ①—⑧）
## 四、负面约束（四段式）
## 关键假设             ← 逐条【原文依据】/【设计补全】
```
