# 场景素材库方法

> 用途：为全剧建立"空间与器物本身长什么样"的素材底库——每个场景/物品/生物一条，喂给生成的底图永远沿用同一张，防画面漂移。
> 与角色库同构：**每个条目一个独立文件夹**，内含 `参考提示词.md`（中文美术注释 ＋ 可独立出图的英文提示词 ＋ 按需的负面词行）。

---

## 一、三类分库与编号法

```
场景素材库/
├── 00_使用说明与索引.md        # 总索引 + 编号表 + 复用检查 + 备注
├── 场景/S<NN>_<编号>_<名>/      # 空间与机位
├── 物品/P<NN>_<名>/             # 道具、器物、信物
└── 生物/B<NN>_<名>/             # 灵宠、妖兽、坐骑
```

**编号法：章号即编号**。
- 场景编号 = `LOC` + 章号 + 层位字母（同章内的多个机位/局部用 A/B/C/D/E 区分）
- 物品/生物用全库流水号（P01、P02…；B01、B02…）
- 编号与分镜提示词里的引用**一一对应**——分镜写到某个场景时直接引用素材库编号，两边不另造名字

**层位字母的规划**：同章内按"空间 → 局部 → 机位"展开——全景空间、局部陈设、首帧机位、收束帧机位，各占一层位；同一空间的日夜/前后态也算独立层位。

---

## 二、出图基线（每个条目统一遵守）

- **风格底色**：写实电影质感（photorealistic cinematic film style）——真实材质、体积光、电影级布光；按题材加东方美学/古制词；16:9；无文字、无水印
- **场景一律空景**：不含人物与灵宠。所有带人物的镜头，由场景空景底图 + 角色参考图合成；首帧机位条目只描述机位、空间与光线
- **中文注释在前，英文提示词在后**：中文注释写"美术注释"（空间尺度、材质状态、光的两色温、可取机位、禁止项）；英文提示词是按注释压缩的可直出提示词
- **负面词行**：现代物件（电线、塑料、玻璃幕墙、现代灯具）、真实宗教符号、文字水印

每条目的 `参考提示词.md` 结构：

```markdown
# <类别> <编号> · <中文名>（<一句话定位>）

> 素材库条目：<路径>｜用法：<喂图槽位说明>

**用途**：<关联章节 / 镜头引用>

**中文注释**：<空间/材质/光线/尺度/可取机位/禁止项>

**提示词（出图）**：<English prompt, … 16:9, no text, no watermark.>
```

---

## 三、跨章复用纪律（防漂移的核心）

1. **同一空间被多条引用时，务必沿用首张底图**——不要每章重出，否则画面漂移
2. 素材库索引里维护一张**跨章复用检查表**：写明"哪几个编号是同一空间/同一张案/同一套器物"，出图时**只换机位与时辰，不重画空间结构**（示例格式：`S02＝S06（同一间房）｜S03＝S08（同一张案）｜S16—S17＝S18（同一片山体）`）
3. 同城不同门、同院落不同方位这类"近似但不是同一处"的，单独注明关系（"同城同门形制、非同一条门"）
4. 编号可以提前预留：分镜未写、素材先备——先按章号占位，后续分镜直接引用

---

## 四、层次隔离（现实层 vs 非写实层）

- **非写实层单独标注**：梦境层、幻境层、闪回风格层、特殊空间（大阵内层等）——只与各自段落配套，**不得混进现实层镜头**
- 多重幻境给每重**色调分工**（如：暖赭 / 暗红与墨 / 冷白与灰），索引里列明
- 非写实层的提示词要显式声明"非写实"（stylized / dreamlike / ethereal），避免被渲染成现实场景

---

## 五、尺度纪律（场景层的安全约束）

- 不出现内脏、断肢、血腥特写、尸体细节与人体部位
- 尸体/遗骸类只作"写意轮廓"（如"沿正中线齐齐分开"的轮廓）；茧/袋类只拍轮廓与极模糊人影
- 材料类道具（兽核、鳞片等）只作**干爽冷光的标本式呈现**
- 镜面类道具（镜子/映照物）**禁清晰人像与性别特征**
- 水池类：按项目边界决定是否为空池、禁人体与水下轮廓
- **文字一律不可辨**：凡符文、牌面、书页、坊标，一律写成"连续回旋的抽象刻线／不可辨认笔画"，绝不成字
- **易混物品单独写区分规则**：两件相似的丝线/材质类道具，写明"颜色/成环与否/是否织成实体"的差异，并规定不得同框图

---

## 六、出图顺序建议

按"骨架先行"排序，保证同一空间、同一道具在不同章之间先有一张权威底图：

1. **贯穿组**：第 1 个空间群的场景 ＋ 贯穿全书的物品（随身武器、饰品）——先定"同一间房、同一张案、同一套器物"的骨架
2. **逐章段组**：按章号顺序补齐每章场景与道具
3. **外景与生物组**：野外空间、妖兽、灵宠
4. **盛会/特殊空间组**：大场面与非写实层
5. **收束组**：末段空间的最终形态

每组出完先自查跨章复用表，再进下一组。

---

## 七、索引文件（00_使用说明与索引.md）必备内容

1. 库的使用说明：出图基线、喂图规则（场景图喂全参考槽位或作情绪底图；物品图作道具特写；生物图作比例与材质参考）
2. 编号规则说明
3. 场景总表（编号｜文件夹｜中文名｜关联章/镜头）
4. 物品总表（编号｜文件夹｜中文名｜关联章）
5. 生物总表（编号｜文件夹｜中文名｜关联章）
6. 出图顺序建议
7. 跨章复用检查表
8. 备注（空景规则、层次隔离、尺度纪律、易混物品区分、与分镜目录的分工：素材库只管"空间与器物长什么样"，机位与生成词在分镜目录）

---

## 八、生物类特殊纪律

- 灵宠/妖兽**只出原形**、严禁拟人化（除非项目明确设定娘化人形，并且幻象与本体用同一口径）
- 有成长/阶段变化的生物写明**两态或三档**（幼年/成年；群/个体/母体），分开单出
- 生物条目注明"绝不化人形、绝不拟人、绝不性感化"等锁定句（按项目边界）
