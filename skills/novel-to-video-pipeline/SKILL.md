# 长篇小说 → AI 视频分镜流水线

一套经过全量实测验证的制片方法论：把一部长篇小说拆成"角色设定库 + 场景素材库 + 逐章分镜提示词"三层素材体系，让每一章都能稳定生成可用的 AI 视频片段。

> 核心特征：一切靠"可校验的硬约束"驱动——每拍 ≤3 件事、每拍台词 ≤18 字、六处对齐、脚本终检。不靠感觉，靠尺子。

## 何时使用

- 要把一本小说（或章节文本）做成 AI 视频/短剧/分镜时
- 需要建立角色设定库（防崩脸、防撞形象）或场景素材库时
- 需要给章节分镜做时长规划、密度校验、量化返工时
- 需要编写/审查"@图片引用式"分镜提示词文件时

## 目录布局（方法模板）

```
<项目根>/
├── <源文本>.txt                    # 原著全文（唯一事实源）
├── 拆分目录.md                     # 分卷索引（每 N 章一个 md）
├── 1-20章节.md …（分卷正文）        # 按固定章数拆分，便于定位行号
├── 角色/                           # 角色库：每角色一个文件夹
│   ├── <角色名>/角色设定.md
│   ├── <角色名>/<角色名>（N）.png   # 定妆参考图
│   ├── _设定资料/                  # 人物资料提取（带原文行号）、风格规范
│   ├── 服装差异化总表.md            # 廓形互斥检查表
│   └── 目录索引.md
├── 场景素材库/                      # 场景/物品/生物三类，每条目一文件夹
│   ├── 00_使用说明与索引.md
│   ├── 场景/S<NN>_<编号>_<名>/参考提示词.md + .png
│   ├── 物品/P<NN>_<名>/
│   └── 生物/B<NN>_<名>/
└── 视频提示词/                      # 核心产出：每章一份分镜提示词
    ├── 00_改写规范.md               # 返工时的"唯一口径"
    ├── 00_时长规划.md               # 全量配时总表
    ├── SC<章号>_第X章_<章名>_<总秒数>秒<段数>段提示词.md
    └── _过程文件/                   # 校验脚本、作业手册、版本备份
```

## 五阶段流程

### 阶段 1 · 文本拆分与索引
1. 原著按固定章数（如每 20 章）拆成独立 md 文件，建立《拆分目录》索引（文件/章节范围/首末章/大小）
2. 建立行号定位习惯：所有资料提取、返工比对都引用"分卷文件 + 行号"
3. 每个项目先建"口径文件"（改写规范、时长规划）再开工——口径先于执行

### 阶段 2 · 角色设定库
每角色一文件夹、一份《角色设定.md》。目标是"美术统筹级"，不是"裁缝工艺单"：
- **意象锚**贯穿全身（脸→发→衣→配饰→异象同一隐喻），意象锚全库唯一
- **壳/芯口诀 + 情态单帧**："〈上层冷态〉是壳、〈下层状态〉从〈具体出口〉漏出来"；"卡在『四字意象未落』的帧"
- **十五个可绘制面部细节** + **不可替代记忆点（实体化异象，随呼吸/情绪变化）**
- **色彩面积纪律**：主色 60% / 辅色 25% / 点缀 10%，诗性色名，禁彩虹式平均堆叠
- **八段式主提示词**：①画质→②构图→③人物神态→④异象特效→⑤发型发饰→⑥服装分层→⑦皮肤质感与饰品→⑧瞳光/背景/光线
- **证据纪律**：关键假设逐条区分【原文依据】与【设计补全】，标注证据强度
- **廓形互斥检查**：领型/开衩方位/鞋履/纹样/主色逐项互斥，全库一张总表

→ 详见 `references/角色设定方法.md`

### 阶段 3 · 场景素材库
- 三类分库（场景/物品/生物），每条目一文件夹：`参考提示词.md`（中文美术注释 + 英文出图提示词）+ 出图
- **章号即编号**：<类别前缀><章号><层位字母>，与分镜里的引用一一对应
- **场景一律空景**（不含人物），只描述机位/空间/光线；人物由角色库参考图合成
- **跨章复用沿用首张底图**，只换机位与时辰——防画面漂移
- **非写实层隔离**：梦境/幻境/闪回单独标注，不得混进现实层
- **尺度纪律**：无内脏/断肢/血腥特写；文字一律不可辨（符文写抽象刻线）

→ 详见 `references/场景素材库方法.md`

### 阶段 4 · 配时规划与分镜提示词
**配时**：段长固定 15 秒（5 拍：0-3/3-6/6-9/9-12/12-15s），只调段数——段数＝需要单独交代清楚的事件数，一段一事。全章台词字数 ÷ 总秒数 ≤5 字/秒。

**分镜提示词文件结构（八件套，顺序固定）**：
1. 标题行（章号｜章名｜总秒数｜段数×15秒｜版本副标题）
2. 导语（段数、字数账、配时理由）
3. 固定要求（首位永远写"外观以参考图为准"；加光源/画幅/边界限制）
4. 对白与声音（语气规则、逐拍核账口径、对白条数分配）
5. 分镜路线表（行数＝段数）
6. 上传顺序表（@图片1—@图片N 映射，首帧不占槽）
7. 每段五块 ①参考图 ②首帧 ③生成词（5 拍）④人物一致性 ⑤画幅风格与风格标签（块数＝5×段数）
8. 末帧交接表（行数＝段数）

**每拍硬规则（违反即返工）**：
- 每拍 ≤3 件事 ＝ 1 主动作 + 1 反应 + 1 次镜头运动（末帧交代句不计）
- 每拍台词 ≤18 字（目标 ≤5 字/秒、上限 6 字/秒）；长句拆到相邻拍，**不许删句、不许改字**
- 首次出现的复杂异象独占一拍；数量级跃迁 ≥1.5 秒且独占一拍；空间转场 ≥2 拍
- **零服装描写**：不写颜色/形制/材质/配饰/发型/妆容，只写身体与发丝动态、道具名称与位置（防换装漂移）
- **六处对齐**：标题/导语/路线表/上传表/①—⑤块数/末帧行数，改一处必须六处同步
- 文件名携带规格（秒数、段数），改配时后改名另存并**删除旧版，不许两版并存**

→ 详见 `references/分镜提示词规范.md`

### 阶段 5 · 校验与交付
每份写完立刻过"四把尺子"，全过才做下一份：
1. **查密度**：每拍事数（超 3 的拍必须为 0）
2. **查超线**：每拍台词 ≤18 字（超线必须为 0）
3. **查结构**：段数＝视频节数＝末帧行数＝路线行数＝①—⑤块数÷5
4. **查服装词**：禁用词命中必须为 0

脚本：`scripts/check_storyboard.py`（一体式，见 `--help`）。原生 PowerShell 脚本设计（查密度/查超线/查台词/终检四把尺子）见 `references/配时与校验方法.md`。

## 贯穿全程的五条工程原则

1. **原文至上**：台词一字不改不增删（只允许重新分配到不同拍/段）；剧情偏差按原文恢复；不许新增原文没有的情节。判断口径："删掉会不会改变剧情——会则留"
2. **外观交给参考图**：角色外观全部由定妆参考图决定，提示词绝不重复描述——两个冲突来源＝换装漂移
3. **一次只做一份**：多份并行＝口径漂移；每份"先读口径文件 → 再读自己那份 → 再读原文 → 改 → 立刻校验"
4. **确定性优先**：能用脚本量的绝不靠人工感觉；密度、字数、结构、词表全上脚本
5. **不许自造约束**：不得替作者做内容取舍，不发明"克制处理"类限制；边界只按项目既有声明执行

## 内容边界基线（写作/生成时的通用纪律）

- 全部角色设定为成年人；不影射真实宗教、门派、人物
- 允许：服装结构产生的露肤、半透质感、神态层面的情绪张力
- 禁止：解剖级与性行为描写、器官词、体液词；暧昧段落停在上沿
- 暴力戏：以光影遮蔽，不拍内脏、断肢、血腥特写
